# Контроль качества питьевой воды на Java

КТ3. Объектно-ориентированная реализация процедурной программы КТ2.
Демонстрационные данные, уведомление и история контроля хранятся в памяти.
Внешние библиотеки не требуются.

## Сборка и запуск

Установите JDK 21. Команды запускаются из папки `src/java`.

```text
java -version
javac -version
javac -encoding UTF-8 -d out Main.java
java -cp out Main
```

Для проверки без отдельного шага сборки в JDK 21 также работает `java Main.java`.
В IntelliJ IDEA откройте папку репозитория, выберите JDK 21 в Project SDK
и при необходимости отметьте `src/java` как Sources Root. VS Code также
подходит: укажите JDK 21 и выполните те же команды в терминале.

## Демонстрационные данные

Вход задан в `Main.main()`. Это учебный сценарий с теми же числами, что в
`src/main.py` из КТ2.

| Параметр | Значение |
| --- | --- |
| Контроль | № 1 от 2026-10-20, ответственный № 101 |
| Проба 1 | 2026-10-20, pH 7.2, мутность 2.2 |
| Проба 2 | 2026-10-20, pH 8.1, мутность 2.5 |
| Границы pH | 6.0–9.0 включительно |
| Границы мутности | 0.0–2.0 включительно |

## Ожидаемый вывод

```text
1. Проверка входных данных
Данные корректны.

2. Проверка качества воды
Проба 1:
  pH: 7.2 — норма
  Мутность: 2.2 — отклонение
Проба 2:
  pH: 8.1 — норма
  Мутность: 2.5 — отклонение

3. Поиск повторных отклонений
Мутность: 2 отклонения

4. Формирование уведомления
Обнаружены отклонения от нормативов качества воды.
Количество отклонений: 2

5. Сохранение истории контроля
Решение: требуются корректирующие действия
Записей в истории: 1
```

## Проверка результата

Выполните `python src/main.py` из корня репозитория, затем запустите Java
по инструкции выше. Текст вывода двух программ должен совпасть полностью.
Внешний тестовый фреймворк для этого прогона не требуется.

UML находится в `models/classes.drawio` в корне проекта. Откройте файл
в diagrams.net или draw.io Desktop. `models/classes.png` — та же схема
для отчёта.

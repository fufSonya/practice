# Контроль качества питьевой воды

## Версия Python

Python 3.10 или выше.

## Запуск программы

Из папки `src` выполните команду:

```bash
python main.py
```

## Зависимости

Программа использует только стандартную библиотеку Python. Внешние библиотеки не требуются, поэтому файл `requirements.txt` не нужен.

## Пример входных данных

Программа запускается с демонстрационными данными, определёнными в `get_demo_data()`:

```python
standards = [
    {"indicator": "pH", "min": 6.0, "max": 9.0},
    {"indicator": "Мутность", "min": 0.0, "max": 2.0},
]

sample_data = [
    {
        "sample_id": 1,
        "date": "2026-10-20",
        "measurements": [
            {"indicator": "pH", "value": 7.2},
            {"indicator": "Мутность", "value": 1.8},
        ],
    },
    {
        "sample_id": 2,
        "date": "2026-10-20",
        "measurements": [
            {"indicator": "pH", "value": 8.1},
            {"indicator": "Мутность", "value": 2.5},
        ],
    },
]
```

## Ожидаемый вывод

```text

Данные корректны.

2. Проверка качества воды

  pH: 7.2 — норма
  Мутность: 1.8 — норма
Проба 2:
  pH: 8.1 — норма
  Мутность: 2.5 — отклонение

3. Поиск повторных отклонений
Повторных отклонений нет.

4. Формирование уведомления
Обнаружены отклонения от нормативов качества воды.
Количество отклонений: 1

5. Сохранение истории контроля
Решение: требуются корректирующие действия
Записей в истории: 1
```

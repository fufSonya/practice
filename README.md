# Учебная практика — водоподготовка и подача питьевой воды

**Автор:** Деревенец С. О.  
**Группа:** ИКБО-10-24

Проект посвящён автоматизации контроля качества питьевой воды перед её подачей потребителю. Программа проверяет входные данные, сравнивает измерения с демонстрационными нормативами, выявляет повторные отклонения, формирует уведомление и сохраняет результат проверки в истории в памяти.

## Содержимое репозитория

- [docs/](docs/) — материалы исследовательского этапа КТ1.
- [src/](src/) — процедурная реализация на Python (КТ2). [Запуск и пример вывода](src/README.md).
- [src/java/](src/java/) — объектно-ориентированная реализация на Java (КТ3). [Сборка и запуск на JDK 21](src/java/README.md).

## Быстрый запуск

Python 3.10 или новее, из корня репозитория:

```powershell
python .\src\main.py
```

Java, из корня репозитория при установленном JDK 21:

```powershell
java .\src\java\Main.java
```

Обе версии на демонстрационных данных находят два отклонения по мутности. Программа работает в командной строке и не требует внешних библиотек.

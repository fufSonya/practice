Для разработки информационной системы контроля качества питьевой воды выбраны IntelliJ IDEA Community Edition в качестве интегрированной среды разработки, язык программирования Java 21, система управления базами данных PostgreSQL 17 и система контроля версий Git.
IntelliJ IDEA Community Edition выбрана благодаря удобной поддержке Java, средств сборки проекта, подключения к системам контроля версий и работы с базами данных. Использование одной интегрированной среды позволяет упростить разработку и отладку приложения.
Java 21 выбрана в качестве языка программирования как современная LTS-версия языка с длительной поддержкой. Язык подходит для реализации бизнес-логики системы, включая регистрацию результатов контроля, проверку показателей питьевой воды на соответствие нормативным значениям и обработку результатов измерений.
PostgreSQL 17 используется для хранения структурированной информации о результатах контроля качества воды, нормативных показателях, проведённых проверках и истории решений. Реляционная модель данных подходит для хранения взаимосвязанных сведений о пробах, показателях, результатах измерений и проверках.
Git используется для контроля версий исходного кода и отслеживания изменений в ходе разработки. Выбор Git также обусловлен требованиями учебной практики, предусматривающими ведение репозитория и наличие истории коммитов, отражающей этапы выполнения проекта.

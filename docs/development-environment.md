Для разработки информационной системы контроля качества питьевой воды выбраны IntelliJ IDEA Community Edition и Visual Studio Code в качестве интегрированных сред разработки, языки программирования Java 21 и Python 3.12.2, система управления базами данных PostgreSQL 17 и система контроля версий Git.
IntelliJ IDEA Community Edition выбрана благодаря удобной поддержке Java, средств сборки проекта, подключения к системам контроля версий и работы с базами данных. Использование данной среды позволяет упростить разработку и отладку приложения на Java.
Visual Studio Code использовалась для разработки и редактирования программной части проекта на Python. Среда предоставляет удобный редактор кода, встроенный терминал и поддержку расширений для Python, что упрощает написание, запуск и отладку программы.
Java 21 выбрана в качестве языка программирования как современная LTS-версия языка с длительной поддержкой. Язык подходит для реализации бизнес-логики системы, включая регистрацию результатов контроля, проверку показателей питьевой воды на соответствие нормативным значениям и обработку результатов измерений.
Python 3.12.2 использовался для разработки отдельной программной части проекта, реализующей проверку качества питьевой воды. Python выбран благодаря простому и понятному синтаксису, а также наличию средств для обработки данных и реализации логики проверки.
PostgreSQL 17 используется для хранения структурированной информации о результатах контроля качества воды, нормативных показателях, проведённых проверках и истории решений. Реляционная модель данных подходит для хранения взаимосвязанных сведений о пробах, показателях, результатах измерений и проверках.
Git используется для контроля версий исходного кода и отслеживания изменений в ходе разработки. Выбор Git также обусловлен требованиями учебной практики, предусматривающими ведение репозитория и наличие истории коммитов, отражающей этапы выполнения проекта.
